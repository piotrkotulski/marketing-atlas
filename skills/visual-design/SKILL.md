# Visual design

Brief well, generate sharper, evaluate honestly.

## When to use

Read `.agents/marketing-context.md` first to match brand voice. If a visual style guide exists, follow it.

## Core frameworks

### Visual brief (one page)
- **Purpose** — what's the asset for and where will it appear
- **Audience** — who sees it
- **One message** — pick one; visuals carry one idea
- **Tone words** — 3 max ("warm, confident, simple")
- **Must-include** — logo, product, faces, text overlay
- **Must-avoid** — competitor colors, clichés, dated styles
- **Format and dimensions** — per channel
- **References** — 3 examples of "this direction"

### AI image generation
For prompt-driven generation:
- Subject + setting + style + lighting + composition + camera/lens (for photoreal)
- For brand consistency: lock seed/style across a batch
- Generate variants, then pick — don't accept the first
- Real people: only use likeness rights you have; AI Act art. 50 requires labeling AI-generated images of identifiable individuals

### Evaluation checklist for any creative
- Stops the scroll in 1 second?
- One message, readable on a phone?
- Brand recognizable in 0.5 seconds?
- Works without sound (for video)?
- Accessible (alt text, contrast)?

### Common mistakes
- Stacking 4 messages in one banner
- Tiny text on mobile
- Generic stock photos that signal "ad"
- Visual style mismatched with brand voice

## Compliance and limits

- Image rights: only use what you have licensed.
- AI Act art. 50 (from 2026-08-02): label AI-generated images, especially of people; keep metadata where possible.
- Accessibility: alt text, contrast ratios (EAA/WCAG 2.2 in EU).
- Misleading visuals (showing features the product doesn't have) violate consumer law.

## Questions to ask the user

1. What's the asset for (ad, social post, hero image, banner)?
2. Where does it live and what are the exact specs?
3. What's the one message?
4. Any brand assets, colors, or references to follow?
